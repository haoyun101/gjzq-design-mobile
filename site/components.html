图标规范

两类管理 · 调用方式 · 描边 / 用色 / 缩放

两类管理 Two Tracks

判断流程:图标纯单色且无动效 → 用字体(方案一);带渐变 / 特效 / 动画 → 用 SVG(方案二)。字体绝不能承载渐变与动画,这是分类的根本原因。

方案一通用单色图标 · IconFont 字体
  • 线性 / 面性,纯单色,无渐变无动画
  • 返回 / 搜索 / 消息 / 设置 / 分享 …
  • 存放 fonts/ · 用 <i class="iconfont icon-xxx"> 调用
  • 颜色用 color 控、大小用 font-size 控
方案二渐变 / 特效图标 · SVG
  • 含渐变 / 内阴影,字体无法承载
  • 底部导航选中态 / 小宝 / 智能体关闭 …
  • 存放 bottom-nav/ · gradient/,直接引用 .svg
  • 动效图标(呼吸 / Lottie)走 SVG+CSS 或外部资源

按钮 / Button

常规 · 文字 · 组合 三类按钮

按钮分三类:常规按钮(实心 / 描边胶囊)、文字按钮(无底色,文字 + 图标)、组合按钮(胶囊内拼接)。 通用规则:高度 6 档 32–92(步进 12),圆角恒为高 ÷ 2(全胶囊);字重深色主 / 浅色主 / 线框用 Medium、灰色用 Regular;颜色全用语义 token(CN / CT / CL)。

选用规则 & 易混辨析
选用规则

风格按操作权重:主操作=深色主按钮(一个区块尽量只放一个主按钮),次操作=浅色主 / 线框,弱操作=灰色 / 文字按钮;档位(尺寸)按容器层级选,不按业务场景。

易混辨析
  • vs 文字按钮 —— 有无背景:常规按钮带底色块,文字按钮无底
  • vs tab —— 动作 vs 切换:按钮触发动作,tab 切换视图
  • vs 底部操作条 —— 单一行动 vs 买 / 卖并列双行动

选用规则 & 易混辨析
选用规则

易混辨析
  • 个股标签 vs 通用标签 —— 个股 = 描边款 r4(透明底);通用 = 面性款 r6(实底 / 淡底),不同族不可混用

  • 红 vs 蓝 —— 红为品牌主色,优先选用;蓝仅作功能色,非主色不滥用
  • 涨跌(GJ 数字)vs 文字标签(苹方) —— 涨跌用数字字体且配色定死;勿用普通文字标签代替涨跌

选用规则 & 易混辨析
选用规则

① 单卡承载一只标的 / 指数的概览:名称 + 最新价 + 涨跌额 / 幅,三行居中。② 底色与数字色同向取色:涨 --CB10 + --CS1、跌 --CB11 + --CS2、平 --CB12 + --CS3,名称恒 --CT1。③ 卡横排 flex 等分、填满容器宽,右侧不留白:扣掉固定区(资金资讯)、左右边距与卡间距后,剩余宽按卡数等分 —— 卡宽 =(容器宽 − 左右边距 − 固定区 − 卡间距 ×(卡数−1))÷ 卡数(见行情场景)。170 是 750 容器 + 144 资金资讯 + 3 卡的算出值,非固定;容器 / 卡数变则卡宽随之变。④ 所有数字(价 / 额 / 幅)一律 GJType · tabular-nums。

易混辨析
  • 行情卡片 vs 涨跌标签 —— 卡片是单标的概览容器(名 + 价 + 涨跌);涨跌标签只是幅度色块,嵌在列表 / 卡内
  • 5% 弱底 vs 实底 —— 行情卡用 5% 弱色(--CB10/11/12)铺底;涨跌标签用实底白字,勿混
  • 等分填满 vs 固定宽 —— 卡flex 等分填满容器,右侧不留白;170 是 750 容器 + 144 资金资讯 + 3 卡的算出值,非写死固定宽
  • 涨 vs 跌 vs 平 —— 仅底色 + 数字色三联切换;名称 / 字号 / 版式三态一致
