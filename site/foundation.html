安全区 / Safe Area

iOS · Android · 750 设计稿v3.11.0

所有关键内容、可点击元素必须落在 安全区 内。状态栏、刘海、底部 Home Indicator 与小白条区域不可放置可交互元素。设计稿基准 750 × 1624(标注值即实现值,750 为唯一基准)。

标准尺寸　Android 与 iOS 各机型的状态栏、导航条、底部安全区高度与内容均不一致(刘海 / 灵动岛 / 直角屏 / 各厂商挖孔屏)。为保证原型输出统一,本系统一律以 iOS 750 尺寸为标准尺寸出图;真机适配时再用 env(safe-area-inset-*) 自适应各机型。

布局与间距 / Layout & Spacing

750 网格 · 4 / 8 基线 · 按页面层级取值v3.11.0

采用 偶数大原则:间距、尺寸、字号尽量取偶数,基础栅格以 4 / 8 px 为最小单位。 页面左右边距与模块上下间距按页面层级取值——一级页(底部 Tab 主页) 16 / 二级页(详情·列表·表单) 24;卡片内边距统一 20;字段级间距取 4 的倍数(特殊场景 2 的倍数)。

字重规则

  • 中文与数字是两套独立标尺,不互相套用。
  • 中文最重 600(Semibold)、不用 700+;数字 GJType 为 400 / 500 / 700、无 600。
  • 正文 / 列表 400 · 标题 / Tab / 按钮 · 数字价格 500 · 中文强调 600 / 数字大额 700。
  • 灰色辅助按钮例外使用 400(见组件页)。
  • 文字字段行高为字体大小的 1.5×。
  • 数字字段行高等于字体大小 (1×)。
  • 字段同时包含数字、文字的,数字可比文字大 2px,设计师可根据情况自行判断;但行高以文字字段行高为准。
  • 规范作用在于定义大多数情况视觉 — 个股等信息高密集页可不受规范限制,特殊设计可自行调整。

颜色 / Color

语义优先 · 涨跌买卖 · token 速查v3.11.0
取色优先级　语义色 token(C 系,带场景)优先;无对应语义 token 时才回退下方「全局色盘」原子色阶;禁止直写 hex。
涨跌与买卖 · 两组语义不可混用

价格方向(行情涨跌)与交易动作(买卖下单)是两组独立语义,分别用 CS / CN 编号。颜色一律用语义编号,不写「CS1 或 R6」这类二选一。

色值对应表 / Color Tokens

v3.11.0 · 白版 / 黑版 · 9 大类v3.11.0

每一项色值都映射到一个语义化 token (例 CT3 表示「次要文本」), 并同时给出 白版 与 黑版 两种主题下的对应色值。 色值可能引用全局色盘 (如 R6) 或直接为 HEX / 含透明度。

双主题原则　深色模式仅通过 data-theme="dark" 覆盖约 39 个底层 token(即下表中黑版与白版不同的项),其余颜色保持不变。品牌红 CP0 与涨跌色 CS1 / CS2 跨主题恒定,不随主题切换。

全局色盘 / Global Palette

7 hues × 19 steps + 18-step gray · 原子色阶v3.11.0

原子色阶,作为语义色的底层来源。仅当没有对应语义 token 时才回退取用;落地一律写语义 token,不直写 hex。
