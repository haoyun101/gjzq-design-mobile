# 业务场景:端外

> 业务域:**端外**(App 之外的客户端页面;含「微信小程序」「浏览器」子域,以后其他端外渠道归此)。
> **取用规则(三层架构)**:做本场景页面时,**优先用本文件**;未覆盖回退「通用组件」→「基础规范」。差异属合法场景覆盖。
> **命名**:组件全限定名带二级前缀「端外/{子域}/…」(子域:微信小程序 / 浏览器),例:端外/微信小程序/导航栏。

## 1. 场景定位与范围
端外渠道页面,遵循各平台规范的专属元素。当前子域:**微信小程序**、**浏览器**。

## 2. 微信小程序(子域)

### 端外/微信小程序/导航栏
- padding `SP5(20px) SP6(24px)`,子元素间距 SP3(12px);左=返回 48;中=标题 36 Medium/S3 居中;右=微信 capsule 胶囊:174×64、圆角 RD7(32px)、描边 1px `#E7E7E7`(微信专属值)、padding SP3(12px)/26,内部「···｜分割线｜○」间距 26,图标色 rgba(0,0,0,.9)。
- capsule 为微信平台规范元素；精确命中SP/RD的参数引用对应token，非标准值保留。

## 3. 浏览器(子域)

### 端外/浏览器/导航栏
- 整体高 176(状态栏 88 + 操作栏 88);背景 `#EDEDED`(浏览器专属值)。
- 左=关闭 `icf_gen_close` 48(色 `--CT1`);中=两行居中:标题 32/48 Medium(S4,`--CT1`)+ 网址 20/30(S8,`#656565`,浏览器专属值),两行间距 −8;右=更多 `icf_gen_more-horiz` 48(色 `--CT1`)。
- 状态栏复用通用组件 `assets/components/status-bar.html`。
