## 1. Overview · 视觉气质

国金证券客户端是一套**亮底、克制、专业**的证券金融界面系统。基底是白与浅灰(`--CB1` 卡片白 / `--CB2` 页面浅灰),让密集的行情数字与资产信息在干净背景上清晰可读;**品牌红 `--R6` 是贯穿全局的唯一主导色「电压」**,承担主要 CTA、买入按钮、品牌标识、强调——如同 Binance 之于黄、Spotify 之于绿,我们走「亮底 + 红」。白色是承载,品牌红是焦点与行动。

系统是**白/黑双主题**:默认白版(`:root`),深色仅翻转底层 57 个语义 token(`[data-theme="dark"]`),品牌红与涨跌色穿透两个主题不变——「只翻转底,不翻转语义电压」。

证券业务带来两条底层语义:**颜色方向**(涨红跌绿、买红卖蓝)与**数字可靠**(资产/价格/涨跌幅密集且必须等宽对齐)。本系统**扁平、无阴影**,层级靠背景分层与 1px 描边表达。

**Key Characteristics**
- 亮底承载 + 品牌红 `--R6` 单一主导电压;辅色(橙黄金绿蓝紫)仅用于图表、标签、特定业务,不参与品牌识别。
- 双主题:白版默认,深色只覆盖 57 个 token;品牌红与涨跌色跨主题不变。
- 颜色方向(引用 SKILL.md 红线 1,此处不另立规则):涨红 `--CS1` / 跌绿 `--CS2`(价格方向);买红 `--CN1` / 卖蓝 `--CN3`(交易动作)。
- 数字与文案分家:价格/金额用 `--font-num` 开 `tnum` 等宽,文案用 `--font-sans`。
- **尺寸基准 = 750px(重要)**:Figma 设计稿基准为 750px,**用 skill 生成的产物(HTML/代码)也统一采用 750px 尺寸**,以便还原后可直接放回 Figma 使用。所有尺寸/字号/间距数值 = 设计稿 750 标注值,不再 ÷2。
  > 历史说明:早期版本曾假设"÷2=375 实现",该假设已废弃;v1.6.2 起 尺寸token、速查表、示例全部统一为 750 值,系统内不再出现 375 语境。
- 圆角友好克制(750):RD2(8px) 按钮 / RD4(16px) 模块内容 / RD6(24px) 模块卡片 / RD7(32px) 主卡片·底部 Sheet 顶角。
- 扁平无阴影,层级靠背景 + 描边。

> 默认产品为**移动端为主**(750 基准画布)。需兼容平板/PC 请告知。

## 2. Colors · 颜色

**取色优先级**:① 优先使用已定义的语义色 token(C 系:CP/CS/CT/CL/CB/CF/CI…,带使用场景);② 语义色没有覆盖的,再用全局色盘原子色(R/G/B/H 等色阶);③ 禁止脱离两者直接写 hex。

三层:**原子色盘**(7 彩色族 × 19 阶 + 灰 18 阶,锚点在第 6 阶)→ **语义 token**(按用途)→ **开发别名**(`--ink-900` 等)。取色走语义 token,语义层无对应才退回原子色。完整 128 个语义 token 精确值见 `design-tokens.css`,下面讲各类**角色**:

- **品牌 CP / 按钮 CN**:`--R6` 是主导色,用于买入/主按钮 `--CN1`、品牌标识、强调。**卖出按钮用蓝 `--CN3`**。**按钮操作的红一律用 `--CN1`**:浅色 / 线框按钮文字、文字操作(Toast「操作」、跳转文案、输入框「全部」、快捷输入选中、弹窗 / 半浮层的「确定」)、加自选图标等;选中态(tab、开关、单复选)、强调和提示仍用 `--CP0` / `--CF1`;输入框光标默认用 `--CP0`;交易买卖输入框买入用 `--CF1`、卖出用蓝 `--CF3`。品牌红焦点而克制,大面积红只属主行动区。
- **文字 CT**:主 `--CT1`、次要 `--CT3`、辅助 `--CT4`、反白 `--CT6`。层级靠这三档拉开,而非堆字号。
- **涨跌 CS(价格方向,作文字色用在数字上)**:涨 `--CS1`(红)、跌 `--CS2`(绿)、平 `--CS3`(灰)。
- **功能 CF**:警告/失败 `--CF1`(红)、提示 `--CF2`、链接 `--CF3`(蓝)、**成功 `--CF7`(绿,操作结果如结果页"操作成功")**。绿在**价格语境**表「跌」(`--CS2`)、在**操作结果语境**表「成功」(`--CF7`)——同色值不同语义。
- **线框 CL**:分割线/描边 `--CL1`、`--CL2`(别名 `--line`)。
- **图标 CI**:主 `--CI1`、次 `--CI2`、弱 `--CI4`、反白 `--CI5`。
- **图表 CH**:多序列按 `--CH1`、`--CH3`、`--CH5`、`--CH7`、`--CH9`、`--CH11`、`--CH13` 顺序取色。
- **背景 CB**:卡片 `--CB1`、页面 `--CB2`、二层 `--CB3`、彩色标签底、遮罩 `--CB18`(深色浮层)/`--CB19`(常规遮罩)等共 55 个。

**同色双角色**:`--R6` 同时是品牌主色(`--CN1`)和涨红(`--CS1`)——同色但语义不同。按用途选 token:按钮用 `--CN1`、涨幅用 `--CS1`,颜色一致不冲突。

## 3. Typography · 字体与排版

### 字体族
- **中文 / 西文:跟随系统**(iOS / 安卓 / 鸿蒙)。设计稿按 iOS 效果呈现,用 `PingFang SC`;实现取 `--font-sans`(系统字体栈)。
- **数字:`GJTypeDisplay`**(`--font-num`),只用于数字与数字符号(时间 / 涨跌幅 / 价格 / 金额 / 百分比等)。字体文件随 skill 提供于 `assets/fonts/GJTypeDisplay-{Regular|Medium|Bold}.ttf`,覆盖 `0–9 $%&()*+,-./:<=>~¥≈≠≤≥`;西文字母不在覆盖范围,走 `--font-sans`。
- 数字字段必须等宽对齐:声明 `font-variant-numeric:tabular-nums`。

### 字重 —— R / M / B 三个代号

| 代号 | 数值 | 字面 | 使用场景 |
|---|---|---|---|
| R | 400 | Regular | 正文内容、辅助信息、列表、未选中态、温馨提示类文字 |
| M | 500 | Medium | 标题、选中状态、强调信息 |
| B | 600 | Semibold | 仅用户明确要求时;系统状态栏时间 |

- 规范里字重一律写代号 R / M / B;实现时按数值取,**任何字体都按数值找对应字面**(PingFang、思源黑体、微软雅黑、OPPO Sans、GJTypeDisplay 同一套)。CSS 写 `font-weight:400 / 500 / 600`。
- ⛔ 页面生成只用 R / M;B 仅用户明确要求时用(状态栏时间固定 B)。

### 字号 —— 中文 CN、数字 NUM 两套
> 生成取 750 值直接作 px。同一档名在两套里可能不同值(S8:中文 20 / 数字 22),引用时必须带后缀:`S8-CN`、`S8-NUM`。

| 档 | 中文 CN 字号/行高 | 中文使用场景 | 数字 NUM 字号/行高 | 数字使用场景 |
|---|---|---|---|---|
| S1 | 44 / 66 | 频道顶部导航 tab 选中文字 | 44 / 66 | 常规列表大数据 |
| S2 | 40 / 60 | 需加强突出的重要信息 / 特殊文本(例:数字金额 / 总资产 / 净资产) | 40 / 60 | 需突出的数据 |
| S3 | 36 / 52 | 页面主标题 / 内容分类标题 / 资产中的常规金额 | 36 / 52 | 常规数据 |
| S4 | 32 / 48 | 一级 tab 选中文字 / 标题文字 / 重要文本 | 32 / 48 | 常规数据 |
| S5 | 28 / 44 | 次级内容标题 / 列表项 / 正文内容 | 28 / 44 | 次要数据 |
| S6 | 26 / 40 | 辅助文字 / 详细说明 | 26 / 40 | 辅助说明数据 |
| S7 | 24 / 36 | 搜索框文字 / 图标文字 / 按钮文字 / 注释 / 提示信息 | 24 / 36 | 辅助说明数据 |
| S8 | 20 / 30 | 标签文字 | 22 / 22 | 图表坐标数据 / 标签数据(图表专用) |
| S9 | — | — | 20 / 30 | 标签数据 |
| S10 | — | — | 48 / 72 | 大数据展示(仅 Medium) |
| S11 | — | — | 52 / 78 | 大数据展示(仅 Medium) |
| S12 | — | — | 56 / 84 | 超大数据展示(仅 Medium) |
| S13 | — | — | 60 / 90 | 超大数据展示(仅 Medium) |

**Figma 文字样式名**:`中文/S{n}-CN-{R|M}`、`数字/S{n}-NUM-{R|M}`(如 `中文/S7-CN-M`、`数字/S8-NUM-R`)。往 Figma 写图层、读 Figma 稿时按此对照。

**行高与混排**
- 常规文本与数字行高均为字号 × 1.5(S8-NUM 22/22 例外)。
- 行高为设计建议,不是硬性规定;个股等信息高密集页可不受字号规范限制。
- 同一字段含数字与文字时,数字可比文字大一号,行高以文字为准。

### 文字缩放(布局遵循偶数原则)
1. **常规情况**:展示不全用「…」截断。
2. **较重要内容必须完整**:按 2px = 1pt = 1dp 逐档缩小字号,最小 20px(10pt / 10dp)。
3. **缩到 20px 仍放不下**:① 换行展示完整;② 没有换行空间时,非必要完整则不换行、用「…」,必要完整则文字从左往右轮播展示。

## 4. Layout · 布局与间距

间距采用 SP0–SP10,圆角采用 RD0–RD10;像素值真源为 `assets/design-tokens.css`,生成 CSS 时引用 `var(--SPn)` / `var(--RDn)`。基本粒度为 4 的倍数(特殊 2 的倍数)。定位偏移(`top/right/bottom/left/inset`)不属间距,写像素;`0` 可直接写 0。

### 页面级间距

| 项 | 一级页面 | 二级页面 | 备注 |
|---|---|---|---|
| 页面左右边距(安全区) | **SP4(16px)** | **SP6(24px)** | 一级 = 有底部 Tab 的主页;二级 = 详情 / 列表 / 表单 |
| 模块(卡片)间距 | **SP4(16px)** | **SP6(24px)** | 纵向与横向相同 |
| 顶部留白 | = 页面边距 | = 页面边距 | 最上方模块卡片距顶部标题栏 |
| 底部留白 | = 页面边距 | = 页面边距 | 最下方模块卡片距页面底部 |
| 列表项高 | 96 / 112 | 同 | 单 / 双行 |

> 各布局类型(含 Feed 流、宫格式)不单设边距:用在哪一级页面,就取哪一级的值。

### 卡片内间距

| 项 | 值 |
|---|---|
| 卡片内容距卡片四边 | **SP5(20px)**(组件未另行规定时使用;组件规范优先,可按方向分别取值) |
| 卡片内内容与内容之间(纵向 / 横向) | **SP4(16px)** |
| 嵌套内容距外层内容四边 | **SP5(20px)** |
| 嵌套内容与内容之间 | **SP4(16px)** |
| 字段 / 图形间距 | SP 档位;既有非标准值保留 |

### 图标与文案的间距
文案层级越高,间距越大;分图标在文案前、在文案后两组:

| 文案层级 | 图标在文案**前** | 图标在文案**后** |
|---|---|---|
| 辅助文案说明、提示 | SP1(4px) | — |
| 常规文案图标组合 | SP2(8px) | SP2(8px) |
| 主要文案图标组合 | SP3(12px) | — |
| 标题文案图标组合 | SP4(16px) | SP3(12px) |
| 搭配偏右的右箭头(如「查看更多 >」) | — | SP0(0) |

### 图标与图标的间距

| 间距 | 场景 |
|---|---|
| SP7(32px) | 标题栏上多个图标之间 |
| SP4(16px) | 模块标题右侧紧跟的多个图标之间 |

### 卡片四级体系
一级背景 → 二级模块 → 三级内容 → 四级字段;间距按上表逐级取值;嵌套圆角见 5 章。

**留白哲学**:信息密度优先;分割线与浅灰分区。

## 5. Shapes · 圆角

圆角使用 RD 档位,统一为 4 的倍数(750 基准;RD10 为既有特例)。小元素小圆角、大容器大圆角;**嵌套时圆角以 4 为单位逐级递减**(如 16 → 12 → 8 → 4),具体按页面场景定,结果取对应 RD token;非标准既有值暂保留。

**卡片圆角默认取值**:通栏背景大卡 RD7(32px)· 模块卡片 RD6(24px)· 模块内容 RD4(16px)。叠加使用时规则不变;设计图另有规定时按设计图,个别极端情况可按场景调整。

| token | 750值(px) | 说明 | 典型场景 |
|---|---:|---|---|
| `--RD0` | 0 | 无圆角 | — |
| `--RD1` | 4 | 最小圆角 | 小标签、复选框 |
| `--RD2` | 8 | 常规模块内容较小圆角 | 按钮、Tab、输入框 |
| `--RD3` | 12 | 常规模块内容较小圆角 | 内部卡片 |
| `--RD4` | 16 | 通用模块内容圆角 | 模块内容(三级) |
| `--RD5` | 20 | 通用模块内容圆角 | Toast、中卡 |
| `--RD6` | 24 | 通用模块卡片圆角 | 模块卡片(二级,含整块列表卡)、中大卡 |
| `--RD7` | 32 | 通栏大卡片背景圆角 | 一级背景卡、底部 Sheet/Modal 顶角 |
| `--RD8` | 40 | 最大圆角 | 开关轨道(组件特例,见组件章) |
| `--RD9` | 999 | 全圆角或胶囊圆角 | 胶囊(进度条、分页符、底导胶囊等)、头像 |
| `--RD10` | 6 | 特殊场景圆角,介于 RD1 和 RD2 之间,尽量不使用 | 组件特例(通用标签等) |

胶囊 / 全圆角用 `--RD9`;圆形可用 `50%`。组件章另有规定的按组件章,不按近似值替换。

## 6. Content · 内容格式(日期与时间)

> 来源:Figma《佣金宝组件库 V2.0》「Date & Time 日期与时间」页的说明。所有页面写日期时间都按本节;组件里的时间(如 C20 资讯列表、C21 倒计时)同样适用。

### 绝对时间 vs 相对时间
- **绝对时间**:明确的时间点,可追溯,用于成交委托、操作记录等。**优先使用绝对时间。**
- **相对时间**:强调「距离现在多久」,**只用于资讯、消息、动态等**。
- 同一页面内日期时间格式保持一致。

| 时间维度 | 展示格式 | 示例 |
|---|---|---|
| 今天 | HH:MM | 09:30 |
| 1 分钟内(相对) | 刚刚 | 刚刚 |
| 大于 1 分钟(相对) | n分钟前 | 12分钟前 |
| 24 小时内(相对) | n小时前 | 12小时前 |
| 昨天 | 昨天 HH:MM | 昨天 09:30 |
| 超过 24 小时(相对) | n天前 | 1天前 |
| 昨天之前,今年之内 | MM-DD HH:MM | 08-28 09:30 |
| 非今年 | YYYY-MM-DD HH:MM | 2025-08-28 09:30 |
| 需要精确到秒 | HH:MM:SS | 09:30:25 |
| 非今年且精确到秒 | YYYY-MM-DD HH:MM:SS | 2025-08-28 09:30:25 |
| 同一天的时间范围 | YYYY-MM-DD HH:MM ~ HH:MM | 2026-08-28 09:30 ~ 15:00 |
| 超过一天的范围 | YYYY-MM-DD ~ YYYY-MM-DD | 2026-08-28 ~ 2026-09-02 |

### 格式定义
| 类型 | 格式 | 示例 |
|---|---|---|
| 年 / 月 / 日 | YYYY-MM-DD;内容型界面(如活动时间)可用汉字 | 2026-08-28 / 2026年02月23日 |
| 时 / 分 / 秒 | HH:MM:SS | 09:30:25 |
| 日期 + 时间 | 中间半角空格 | 2026-08-28 09:30:25 |
| 范围 | 「~」连接 | 2026-08-28 ~ 2026-09-02 |
| 时制 | 24 小时制 | 09:30 / 18:30 |
| 补零 | 月、日、时、分、秒都两位 | 09-02 / 09:03 |

- 数字一律用 `--font-num`(见 §3)。

## 8. Do's and Don'ts · 最佳实践(软建议)

> 红线(涨绿跌红、硬编码、深色色值等)见 `SKILL.md` 硬规则;此处只讲不上升到红线的审美与质量建议。

### Do
- 品牌红 `--R6` 留给主 CTA 与少数强调,焦点而克制。
- 文本层级用 CT1/CT3/CT4 三档拉开,而非堆字号。
- 层级用背景色差 + 1px 描边,保持扁平。
- 信息密集页紧凑排布,靠分割线分区。

### Don't
- 别用 `--R6` 装饰性铺底——大面积红只属主行动区。
- 别用 B(600)及以上字重——页面生成只用 R(400)/ M(500)。
- 别用阴影制造层级——本系统扁平,用背景与描边。
- 别靠堆字号拉层级——优先用文字色三档。

## 10. Agent Prompt Guide · 生成引导

### 快速取色参考

### 语义 token → hex 速查(免多级跳转)
`--CP0`=#F93838 品牌红 · `--CS1`=#F93838 涨 · `--CS2`=#05B063 跌 · `--CT1`=#0F0F1B 主文本 · `--CT3`=#55555E 次文本 · `--CT4`=#87878D 辅文本 · `--CT6`=#FFFFFF 反白 · `--CL1`=#DDDDDD 一级分割/默认描边 · `--CL2`=#EEEEEE 常规分割线 · `--CL3`=#F93838 红描边 · `--CB1`=#FFFFFF 卡片白 · `--CB2`/`--CB3`=#F2F4F8 页面灰/弱底 · `--CF1`=#F93838 · `--CF3`=#2B73FF 功能蓝。完整链路见 assets/design-tokens.css。
- 页面背景 `--CB2` · 卡片 `--CB1` · 主文本 `--CT1` · 次要文本 `--CT3`
- 品牌红/买入 `--CN1` · 卖出 `--CN3`(蓝) · 分割线 `--CL1` / `--CL2`
- 涨 `--CS1`(红) · 跌 `--CS2`(绿) · 链接 `--CF3`(蓝) · 成功 `--CF7`(绿,操作结果)

### 示例组件 prompt
- 「行情卡片:`--CB1` 白底,圆角 `--RD4`(16),1px `--CL1` 描边。股票名 `--CT1` 32(S4-CN)500;代码 `--CT4` `--font-num` 24(S7-NUM);现价右对齐 `--font-num` 36(S3-NUM)500;涨幅为正 `--CS1`(红)、为负 `--CS2`(绿),`--font-num` 28(S5-NUM)。」
- 「底部操作栏:直接用 C19 底部操作栏-2-常规——次按钮 按钮-线框-XL、主按钮 按钮-主色-XL,1:1;顶边线默认不显示。」
- 「总资产卡:背景用品牌渐变 `--grad-red` 或运营切图;总资产数字 `--font-num` 40(S2-NUM)500,反白 `--CT6`;标签 26(S6-CN)。」

### 迭代步骤
1. 铺 `--CB2` 页面底 + `--CB1` 卡片(+1px `--CL1`),定层级。
2. 文本走 CT1/CT3/CT4 三档定信息层级。
3. 涨跌数字用 CS1/CS2,数字字段统一 `--font-num` + tnum。
4. 买入用 `--CN1`(红)、卖出用 `--CN3`(蓝)。
5. 圆角统一档位,嵌套子元素小一档;不用阴影。
6. 跑 SKILL.md 自检清单,重点查涨跌/买卖色与硬编码。
