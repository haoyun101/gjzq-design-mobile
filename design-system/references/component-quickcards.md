# 组件速查卡 · Component Quickcards

> **用途**:每个已登记组件一张小卡——**全限定名 + 形态变体(辨识特征)+ 关键值 + 复用方式**。
> **为什么先读这个**:选组件 / 判形态前先查本卡,命中后再去 `components.md` 对应章读完整规格、`view` 参考实现整段复用。**不必为"长什么样"先 view 整份 components.md 或整个 demo 文件**。
> **硬规则(SKILL.md 闸门 A2)**:命中库组件 = 必 `view` 参考实现复用、动手前先 `get_design_context` 看截图核形态;**禁止凭 metadata 矩形尺寸脑补形态**。
> 真值以 `components.md` 对应章 + `design-tokens.css` 为准;本卡是导航不是真源,数值有出入以章节为准。

## C01 常规按钮 · `按钮-{样式}-{档}`
- **变体**:样式=主色 / 浅色 / 线框 / 灰色 / 胶囊(仅 XL);档=XXS/XS/S/M/L/XL(六档,**圆角 RD9 全胶囊**);状态=默认 / 点击 / 禁用。
- **辨识**:有背景实心或线框、全胶囊圆角。一区块/页尽量只一个主按钮(主色);底部整宽用通栏档。
- **易混**:vs 文字按钮(有/无背景);vs tab(触发动作/切换视图)。
- **Figma 层级**:两层——外层组件(无填充、竖向自动布局)→ 内层「按钮」帧(红底等填充、胶囊圆角、横向 FILL、左右内边距 80)→ 文案。在 Figma 里改按钮宽度要看内层「按钮」帧的宽度设置。
- **复用**:规格见 `components.md#一`;参考实现 `assets/components/button.html`;Figma 编码见 `assets/figma-codes.json`。

## C02 文字按钮 · `文字按钮-{类型}-{24|26|28|32}`
- **变体**:类型=更多 / 更多-list / 展开 / 收起 / 说明;字号 24 / 26 / 28 / 32;图标、文字可各自隐藏。字重全部 Regular,文字 `--CT4`、图标 `--CI3`。
- **辨识**:无背景纯文字、常带方向/功能图标,多作其他组件右侧操作位(如标题栏)。
- **易混**:vs 常规按钮(权重/背景);vs 链接;vs tab。
- **复用**:参考实现 `assets/components/text-button.html`;规格 `components.md#二`;Figma 编码见 `assets/figma-codes.json`。

## C03 导航栏-底部 · `导航栏-底部` ★★一名两态,**翻车高危区**
> ⚠️ **先走选型路由**:做**一级页面**(首页/自选/我的/交易/理财)底导 → 用【智能体球版】;**通用底导**仅"业务要自定义 N-tab 通用栏"时用。**动手前必 `get_design_context` 看截图确认是哪一种**(凭 metadata `Rectangle 750×166` 脑补成白底 = 本系统实测最大返工源)。
- **【一级页面·智能体球版】(业务变体,bottom-info-bar.html)**
  - **辨识**:持久带**悬浮智能体球** + **底部信息栏**(随 active tab 变);明/黑双肤。
  - **关键值**:智能体球(132×128,球+声波)→ 从发布仓库拉取 `resources/avatars/avatar-agent-orb.png`(同 C34「思考中」);信息栏多态:首页=异动通知60 / 自选=个股异动84↕盯盘356 / 我的=大家都在看60 / 交易·理财=无栏;信息栏顶圆角 RD7(32px)、渐变底 CB38/39/40→CB1。
  - **复用**:生成页面时优先读 `assets/components/bottom-info-bar.usage.md` + 本卡,在 BOM 中钉到 `assets/components/bottom-info-bar.html`;默认不全文读取参考实现。只有修改/排查该组件本身时才读全文。
- **【通用底导】(规则集/基准,bottom-nav.html)**
  - **辨识**:纯 **N 等分白底条**,**无**智能体球。
  - **关键值**:整高 166(条98+Home68)、图标 48、图标-文字间距 SP1(4px)、文字 24/S7 **Regular 400**(底导特例)、选中 `--CP0` / 未选 `--CT3`、背景 `--CB1`、顶部分割线 `--CL2` 1px;tab 2–6 个,屏宽 ÷ N 等分;示意图标用 `assets/icons/bottom-nav/` 五组(home/watchlist/trade/finance/mine,**active 渐变 + inactive 单色成对**,勿用无关字体图标顶替)。
  - **复用**:整段复用 `bottom-nav.html`。
- **一句话辨识**:**有悬浮球+信息栏 → 智能体球版;纯 N 等分白条 → 通用底导。**
